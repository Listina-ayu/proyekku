# HeruAI

Chatbot web heuristik tentang Kabupaten Bojonegoro, dibuat dengan HTML, CSS, dan JavaScript murni. Tidak menggunakan framework, API, backend, paket eksternal, atau koneksi internet.

## Menjalankan

Buka `index.html` langsung di browser modern. Tidak perlu instalasi atau proses build.

## Cara kerja dan batasan

- Pertanyaan dicocokkan dengan kata kunci dan konteks sederhana pada `knowledge.js`.
- Sapaan, obrolan ringan, pertanyaan umum tentang Bojonegoro, dan tindak lanjut percakapan ditangani oleh aturan di `app.js`.
- Cakupan mencakup wilayah, pemerintahan, kependudukan, layanan publik, ekonomi/pertanian, pendidikan, kesehatan, sosial, budaya, wisata, kuliner, transportasi, pekerjaan, olahraga, infrastruktur, lingkungan, dan bencana.
- Pesan tidak dikirim atau disimpan; seluruh interaksi berjalan sementara di browser.
- Ini bukan model AI generatif dan tidak dapat menjawab semua topik secara faktual. Jika tidak menemukan kecocokan yang cukup kuat, HeruAI akan menyatakan keterbatasannya.
- Angka dan layanan yang berubah dari waktu ke waktu perlu diperiksa melalui instansi/sumber resmi. Data kependudukan 2020 dan data sarana ibadah 2025 diberi tahun rujukan.
- Untuk keadaan yang mengancam keselamatan, hubungi kanal darurat resmi atau petugas setempat. Jangan membagikan data pribadi di chat.

Basis pengetahuan diringkas dari dokumen “Rangkaian Pengetahuan Kabupaten Bojonegoro untuk HeruAI”.
